
# AttendX Test Scripts

## Project Description
AttendX is a student attendance application.
This repository contains sample automated tests
for login validation and attendance marking.

## Test Scripts

1. login_test.py
   - Tests valid login credentials.
   - Tests invalid login credentials.

2. attendance_test.py
   - Tests marking attendance as Present.
   - Tests invalid attendance status.

## Technology Used
- Python
- unittest
- Git
- GitHub

## How to Run
Run the following commands from the repository folder:

python -m unittest login_test.py
python -m unittest attendance_test.py
